Тот же SONAR.
Другая форма вкладки.

Меняется только верхний ряд: контур, радиусы, скос и кромка. Ниже — исходная разметка и стили SONAR 0.4.29, выгруженные из работающего браузера.

Капсула

Полукруглые торцы, непрерывная тонкая обводка.

В полном размере

Вкладки нажимаются: проверь активное состояние и наведение. Содержимое окна — настоящий снимок SONAR. На узком экране ряд можно прокрутить вбок.

CSS для этой формы

Селекторы используют настоящий #tabs .tab. Файл подключается после стилей SONAR. В этой демонстрации код приложения не изменяется.
